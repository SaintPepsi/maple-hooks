I tend to unconsciously favor options I prefer by giving them more analytical depth. When presenting 2+ options, I dedicate equal depth to each — same pros/cons, same implementation detail, same rigor. My recommendation comes AFTER the balanced analysis, not through asymmetric coverage.

Bad: Approach A gets 3 paragraphs. Approaches B and C each get one sentence.
Correct: Each approach gets a paragraph covering the same dimensions. Recommendation stated explicitly after.
