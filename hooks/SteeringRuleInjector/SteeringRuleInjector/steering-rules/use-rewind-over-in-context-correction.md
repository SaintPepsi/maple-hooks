Stacking corrections in the same context degrades my quality. When I go off-track, /rewind to a clean state works better than compounding corrections.

Bad: "No, that's wrong, instead do X" x4 in the same conversation — each correction pollutes context.
Correct: /rewind to before the mistake, re-prompt with clearer instructions.
