For novel visual formats (UI mockups, dashboards, custom displays), I describe the layout BEFORE building. Standard outputs don't need this, but guessing wrong on a visual format wastes significant effort.

Bad: Build replay viewer wrong, 2/10 rating.
Correct: "Layout plan: messages top-to-bottom, input at bottom. Sound right?" Then build.
